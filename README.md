# Quant Trading

This project contains data, data cleaning and analysis, trading algorithms and backtesting engine.

## Setup

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## Data

The H-1B data is coming from https://www.dol.gov/agencies/eta/foreign-labor/performance

The data is stored in Vercel BLOB storage: https://vercel.com/albert-cares/~/stores/blob/store_qZmQvUTHYGIBAKhx/browser
